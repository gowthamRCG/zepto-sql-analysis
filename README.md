# Zepto E-Commerce SQL Data Analysis Project

##  Project Overview
This project analyzes Zepto e-commerce product data using SQL Server.
The goal is to clean raw data, perform exploratory analysis, and extract
business insights useful for inventory and revenue decisions.

##  Tools Used
- SQL Server
- SSMS
- CSV Data Import
- Git & GitHub

##  Dataset
- Product details including MRP, discounts, availability, quantity, and category.

##  Data Cleaning Steps
- Removed products with invalid pricing (MRP = 0)
- Converted prices from paise to rupees
- Checked for null values
- Verified duplicate product names

##  Key Business Insights
- Identified top 10 highest discount products
- Analyzed out-of-stock high-value products
- Calculated category-wise revenue
- Identified revenue-driving categories

##  Business Value
- Helps track stock movement
- Improves discount strategy
- Identifies revenue loss due to stockouts
- Supports inventory planning decisions

##  Real-World Use Case
Daily SQL analysis tasks performed by data analysts in e-commerce companies.
